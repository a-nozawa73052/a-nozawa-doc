```mermaid

    IC --> SR[("shipping_requests")]
```

- `direct_shipments`への登録は、import_contract内の`neos_item_pac_cd`ハードコード（中カテ）判定のみで決まる

## 3. 「顧客直送 or 代理店直送」の判断基準（決定木）

```mermaid
flowchart TD
    START(["送り状Excel出力\n（直送対象と判定された依頼）"]) --> Q1{"shipping_requests.neos_item_cd は\ndirect_shipment_itemsに存在するか"}

    Q1 -->|存在しない| R0["直送対象外\n→ branch_replacementの\n管轄支店情報を出力"]

    Q1 -->|存在する| Q2{"該当する\ndirect_shipment_categories.\nshipment_type_cd"}

    Q2 -->|"1（顧客直送）"| Q3{"shipping_requests.\nshipping_destinationに\n値がある？"}
    Q3 -->|あり| R1["【顧客直送】\n名称＝shipping_destination\n住所/TEL/郵便番号＝contracts.customer_*"]
    Q3 -->|なし| R2["【顧客直送・フォールバック】\n名称＝contracts.customer_name\n住所/TEL/郵便番号＝contracts.customer_*"]

    Q2 -->|"2（代理店直送）"| R3["【代理店直送】\n名称/住所/TEL/郵便番号\n＝contracts.agency_*"]

    R1 --> COMMON["申し送り事項:\nshipping_requests.shipping_message\nに値があれば常に出力\n（顧客直送・代理店直送共通）"]
    R2 --> COMMON
    R3 --> COMMON

    style Q1 fill:#ffe0e0
    style Q2 fill:#ffe0e0
    style Q3 fill:#ffe0e0
    style R0 fill:#f0f0f0
    style R1 fill:#d4edda
    style R2 fill:#d4edda
    style R3 fill:#d1ecf1
```

**判断基準まとめ**

| 段階 | 判定内容 | 参照データ |
|---|---|---|
| ① 直送対象か否か | `neos_item_cd`が直送案件マスタに登録されているか | `direct_shipment_items` |
| ② 顧客直送 or 代理店直送 | ①で該当したカテゴリの直送種別CD | `direct_shipment_categories.shipment_type_cd` |
| ③ 顧客直送の中での宛先優先順位 | `shipping_destination`の値の有無 | `shipping_requests.shipping_destination` → なければ`contracts.customer_name` |

> ⚠️ ①②の判定はマスタにUSEN MUSIC自体のデータ（`neos_item_cd`・カテゴリ）が登録されて初めて正しく機能する。現時点では未登録のため、事業部・NeOS側への確認結果を待って初期データを整備する必要がある（詳細は改修概要書 10章）。

## 4. import_contract内の「2つの中カテ判定」の位置づけ（参考）

送り状出力の判定（上記2・3）とは別に、import_contract内部には**変更しない**独立した中カテ判定が2つ残る。

```mermaid
flowchart LR
    TSV["contract.tsv\n1行（neos_item_pac_cd）"] --> D1{"① direct_shipments\nINSERT対象か\nM0328/M0335/M0362/M0374/M0379"}
    TSV --> D2{"② 直送センター固定\n対象か\nM0328/M0331/M0335/M0333/\nM0342/M0347/M0362/M0365/M0374/M0379"}

    D1 -->|Yes| DS2[("direct_shipments\nにINSERT")]
    D2 -->|Yes| ROUTE["shipping_requests.\nrequest_branch_cdを\n直送センター固定値に上書き"]

    style D1 fill:#fff3cd
    style D2 fill:#fff3cd
```

①②は目的（NP審査追跡 / 物流ルーティング）も対象コード範囲も異なる別ロジック。今回はどちらも**判定方式は変更せず**、`M0379`（代理店直送）をそれぞれのハードコードリストに追加するのみ。
