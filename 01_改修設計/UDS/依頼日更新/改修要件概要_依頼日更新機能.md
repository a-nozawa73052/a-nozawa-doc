# 改修仕様書：依頼日更新機能（メンテナンス画面）

## 概要

メンテナンス画面（`/manage/master/mainte`）に、`shipping_requests` テーブルの `request_date`（依頼日）を任意の日付に更新する機能を追加する。

---

## 対象ファイル

| 役割 | ファイルパス |
|------|-------------|
| コントローラ | `src/public_html/fuel/app/modules/manage/classes/controller/master/mainte.php` |
| ビュー | `src/public_html/fuel/app/modules/manage/views/master/mainte/index.php` |
| モデル | `src/public_html/fuel/app/classes/model/shipping/request.php` |

---

## 機能要件

- 依頼IDの末尾の数字を入力する（例：`S00000008092` → `8092`）
- カレンダーで変更後の依頼日（`request_date`）を指定する
- 更新ボタンを押すと `shipping_requests.request_date` が指定日付に更新される
- 対象は全依頼タイプ（N/S/D/E/C）

---

既存のフォームブロックと同じスタイルで、以下を末尾に追加する。

```
【見出し】依頼日を更新

【説明文】
・依頼IDの末尾の数字のみ入力してください　例：S00000008092 → 8092
・更新対象の新しい依頼日をカレンダーで選択してください

【入力欄①】テキスト入力
  - name: id
  - type: text
  - placeholder: 依頼IDを入力（末尾の数字のみ）

【入力欄②】日付入力
  - name: request_date
  - type: date（ブラウザ標準のカレンダーUIが表示される）

【ボタン】更新
```

---

## バリデーション（コントローラ側）

| 条件 | エラーメッセージ |
|------|-----------------|
| `id` が空 | 「依頼IDを入力してください」 |
| `request_date` が空 | 「依頼日を入力してください」 |
| 指定IDのレコードが存在しない | 「存在しない依頼IDです」 |

---

## 処理フロー

```
POST /manage/master/mainte/update_request_date
↓
1. Input::post('id') と Input::post('request_date') を取得
2. 入力値のバリデーション
3. shipping_requests を id で検索（deleted_at が null のもの）
4. 見つかった場合、request_date を更新して save()
5. set_info_message でメッセージ表示
6. /manage/master/mainte にリダイレクト
```

### 2. コントローラ（mainte.php）への追記

`action_change_store_stock()` の後ろ（クラスの閉じ括弧 `}` の前）に以下のメソッドを追加する。

```php
public function action_update_request_date()
{
    $id = Input::post('id');
    $request_date = Input::post('request_date');

    if (empty($id)) {
        $this->set_error_message('依頼IDを入力してください');
        Response::redirect('/manage/master/mainte');
    }
    if (empty($request_date)) {
        $this->set_error_message('依頼日を入力してください');
        Response::redirect('/manage/master/mainte');
    }

    $shipping_request = \Model_Shipping_Request::query()
        ->where('id', $id)
        ->where('deleted_at', null)
        ->get_one();

    if ($shipping_request === null) {
        $this->set_error_message('存在しない依頼IDです');
        Response::redirect('/manage/master/mainte');
    }

    // date型のinputはY-m-d形式で来るため、既存コードの慣例に合わせてY/m/d形式に変換
    $shipping_request->request_date = date('Y/m/d', strtotime($request_date));
    $shipping_request->save();

    $this->set_info_message('依頼ID:' . $id . ' の依頼日を ' . $request_date . ' に更新しました。');
    Response::redirect('/manage/master/mainte');
}
```

| 異常系② | 日付を空にして送信 | 「依頼日を入力してください」が表示される |
