# 改修概要 — 保守委託権限 新規追加

---

## 1. 概要

ウェルシアの通信端末保守サポート（24H365日体制）において、グループ会社TACTが一次受けのカスタマーセンター業務を担当することに伴い、TACTがUDSで修理交換対応を行うための新権限「保守委託」を追加する。

操作範囲は現地ユーザーと同等だが、修理依頼時の発送先ロジックおよびシリアル入力フローのみ異なる。

---

## 2. 追加機能・変更点サマリー

| # | 種別 | 変更内容 |
|---|---|---|
| 1 | 新規 | 「保守委託」権限（user_div=7）を追加 |
| 2 | 新規 | 保守委託ユーザー向けコントローラー・ナビゲーションを追加 |
| 3 | 仕様変更 | 保守委託からの修理依頼時、発送先をオムロンに固定 |
| 4 | 新規 | 引き当て画面にシリアル取得確認チェックボックスを追加（保守委託のみ） |

### 4-4. 引き当て画面チェックボックス（保守委託のみ）

**`src/public_html/fuel/app/modules/manage/views/hoshu/assign/serial.php`**（新規）

Branch の引き当て画面ビューをベースに以下を追加する。

- チェックボックス（`id="serialConfirmCheck"`）を引き当てボタンの上に配置
- 引き当てボタンの活性条件をJSで制御：シリアル登録済み かつ チェックON の両方を満たす場合のみ活性

```javascript
// 保守委託向け引き当てボタン制御
function updateAssignBtn() {
    var serialDone  = $('.js-serial-registered').length > 0; // シリアル登録済みフラグ
    var checkDone   = $('#serialConfirmCheck').is(':checked');
    if (serialDone && checkDone) {
        $('.js-assign-btn').removeClass('is-disable');
    } else {
        $('.js-assign-btn').addClass('is-disable');
    }
}
$('#serialConfirmCheck').on('change', updateAssignBtn);
```

### 4-5. シリアル入力モーダルチェックボックス（保守委託のみ）

**`src/public_html/fuel/app/modules/manage/views/dialog/barcode.php`**

保守委託ロール（user_div=7）かつ引き当て画面（`assign/serial_save`）のキーボード入力モードにのみチェックボックスを表示する。

- チェックボックス（`.js-hoshu-tel-check`）をシリアル入力フィールドの下に配置
- Enter キーによる登録処理をJSで制御：シリアル入力済み かつ チェックON の両方を満たす場合のみ登録実行

```javascript
// 保守委託モーダルのEnter制御
$('.js-key-input').on('keydown', function(e) {
    if (e.keyCode !== 13) return;
    e.preventDefault();
    var hasSerial = $(this).val().length > 0;
    var checked   = $('.js-hoshu-tel-check').is(':checked');
    if (!checked) {
        // チェックなしでEnter → エラーメッセージ表示
        $('.js-hoshu-tel-error').show();
        return;
    }
    if (!hasSerial) return;
    $('#barcodeValue').val($(this).val());
    var form = $('#barcodeForm');
    form.attr('action', form.find('#barcodeNextUrl').val());
    form.submit();
});

// チェックを入れたらエラー解除
$('.js-hoshu-tel-check').closest('label').on('click', function() {
    setTimeout(function() {
        if ($('.js-hoshu-tel-check').is(':checked')) {
            $('.js-hoshu-tel-error').hide();
        }
    }, 50);
});
```

チェックなしでEnterした場合の表示：
- チェックボックスエリアを赤枠にハイライト（シェイクアニメーション付き）
- エリア下部に「確認チェックを入れてから Enter を押してください」を赤字で表示
- チェックを入れるとエラー表示を解除

## 6. リリース手順

依存関係があるため以下の順序で実施する。

```
① コードデプロイ
② 支店マスタ（UDS管轄倉庫置換マスタ）にオムロンを登録
③ 支店在庫マスタにオムロンのエントリを追加        ← ②の後
④ ユーザーマスタCSVで保守委託アカウントを登録      ← ②の後
```

| 作業 | 担当 | 登録値 |
|---|---|---|
| コードデプロイ | 開発 | — |
| 支店マスタ登録 | 運用 | `branch_cd`: `0500010000_08` / `branch_name`: `オムロン品質管理在庫倉庫` |
| 支店在庫マスタ登録 | 運用 | `branch_cd`: `0500010000_08` |
| ユーザーアカウント作成 | 運用 | `user_div=7` / `jurisdiction_branch_cd=0500010000_08` / `jurisdiction_branch_name=オムロン品質管理在庫倉庫` |
