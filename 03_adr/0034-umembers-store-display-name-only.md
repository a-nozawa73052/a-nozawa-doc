# ADR-0034: UMEMBERSの画面では店舗コードを直接出さず、店舗名を基本に表示する

- 関係者: 話者名が文字起こしに含まれないため要確認（会議は「ACE-UM開発定例_20261104」）
- 出典: 文字起こし 00:00:00〜00:02:52（Geminiメモ: https://docs.google.com/document/d/1cY5J7kJj5DL2sq4CKuffvAGRxIg6Aru8ExA3xBEKeDc）
- 備考: 冒頭は誤変換が特に多く、どの画面のどの項目の話かの特定に自信がない。住所の扱いは未確定。

## コンテキスト
- 会議では、UMEMBERSの画面（画面案を見ながら）で、店舗に関する表示項目を整理した。
- ACE側の店舗コード（発言は「サービス定席コード」「エースポコード」と聞こえる。正式名称は要確認）は、お客様に向けて出すものではない。
- お客様の画面では、店舗は「店舗」という言葉で小さく表示される想定である。
- 店舗コードが必要になる場面は、問い合わせや確認のときに参照する用途である。

## 決定
- お客様の画面には、店舗コードを直接は出さない。店舗は店舗名として表示する。
- 電話番号は、わざわざ表に出す必要がない（発言: 「番号とかもなんかわざわざ表に出す必要あんのかもしれない」「全然いらない」）。
- 事業者の項目は不要という発言があった（発言: 「業者いらない」。意味は要確認）。

## 理由
- お客様に対してコードを出さないため。
- 電話番号などは、表に出す必要性が低いため。

## 影響・トレードオフ
- 問い合わせ対応などで店舗コードを確認したい場合は、お客様向けの画面以外で参照できる必要がある（要確認）。

## 検討した代替案
- 住所は、店舗名だけでは分からない場合がある（例: 「渋谷店東」のような名称）ため、出す案も話題に出た。結論は聞き取れず、要確認。

## 未解決事項・次のアクション
- [ ] 住所を表示するか、表示する場合の条件を決める。
- [ ] 問い合わせ対応用に、店舗コードをどこで確認できるようにするかを決める。
- [ ] 「事業者」の項目の扱い（不要かどうか）を確認する。

## 補足
- Geminiメモは、「店舗コードをお客様の画面に直接出すことはなく、店舗名として小さく表示される、または問い合わせや確認時に参照するための仕様」「店舗コードや住所・電話番号の表示項目の必要性について整理が行われている」としている。
- 文字起こしの「エース」はACEと補正した。
