# ADR-0034: UMEMBERSの画面ではサービス提供先コードと業種コードを出さず、店舗名を基本に表示する

- 関係者: 話者名が文字起こしに含まれないため要確認（会議は「ACE-UM開発定例_20261104」）
- 出典: 文字起こし 00:00:00〜00:02:52（Geminiメモ: https://docs.google.com/document/d/1cY5J7kJj5DL2sq4CKuffvAGRxIg6Aru8ExA3xBEKeDc）
- 備考: 冒頭は誤変換が特に多く、どの画面のどの項目の話かの特定に自信がない。住所と店舗CDの扱いは未確定。文字起こしの「サービス定席コード」はサービス提供先コード、「業者いらない」は業種コードは不要の意味である（担当者確認済み）。

## コンテキスト
- 会議では、UMEMBERSの画面（画面案を見ながら）で、店舗に関する表示項目を整理した。
- ACE側の「サービス提供先コード」（文字起こしでは「サービス定席コード」と誤変換）は、お客様に向けて出すものではない。サービス提供先コードと店舗CDは別の値である。
- お客様の画面では、店舗は「店舗」という言葉で小さく表示される想定である。
- コードが必要になる場面は、問い合わせや確認のときに参照する用途である。

## 決定
- お客様の画面には、サービス提供先コードを直接は出さない。店舗は店舗名として表示する。
- 電話番号は、わざわざ表に出す必要がない（発言: 「番号とかもなんかわざわざ表に出す必要あんのかもしれない」「全然いらない」）。
- 業種コードは不要とする（発言: 「業者いらない」）。

## 理由
- お客様に対してコードを出さないため。
- 電話番号や業種コードなどは、表に出す必要性が低いため。

## 影響・トレードオフ
- 問い合わせ対応などでコードを確認したい場合は、お客様向けの画面以外で参照できる必要がある（要確認）。

## 検討した代替案
- 住所は、店舗名だけでは分からない場合がある（例: 「渋谷店東」のような名称）ため、出す案も話題に出た。結論は聞き取れず、要確認。

## 未解決事項・次のアクション
- [ ] 住所を表示するか、表示する場合の条件を決める。
- [ ] 店舗CD（サービス提供先コードとは別の値）を画面に表示するか、問い合わせ対応用にどこで確認できるようにするかを決める（文字起こし 00:00:38 に店舗コードを問い合わせ時に参照したい趣旨の発言があるが、結論は聞き取れない）。

## 補足
- Geminiメモは、「店舗コードをお客様の画面に直接出すことはなく、店舗名として小さく表示される、または問い合わせや確認時に参照するための仕様」としている。Geminiメモの「店舗コード」は、サービス提供先コードと店舗CDのどちらを指すか区別されていない（要確認）。
- 文字起こしの「エース」はACEと補正した。
