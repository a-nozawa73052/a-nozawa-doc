# ADR-0019: モバイル版は専用ドメインを発行せず、Web版と同じパス形式で提供する

- 決定者・関係者: 野澤有沙、部屋智洋、森晨滉（UDS）、佐々木航太（不参加。確認内容を野澤が代弁）
- 出典: 文字起こし 00:11:15〜00:12:21（Geminiメモ: https://docs.google.com/document/d/1P7lDzxiJ3AeSJfOtVibopww7ppry9sw6rebAX4_oipg）

## コンテキスト
- 部屋さんから共有されたインフラ構成図では、モバイル用に専用ドメインを発行する前提に見えた。
- 当初は専用ドメインを発行する設計にする話だったが、結局発行しなかった経緯がある。
- 現在のステージング環境のモバイル用URLは、新しいドメインを発行せず、既存のWeb版と同じ形式で、パスを分ける形（文字起こしでは「スラッシュモバイル／ブランチ」のような形）で作っている。

## 決定
- モバイル用のアクセスは、新しいドメインを発行せず、既存のWeb版と同じ形式のパスで提供する（野澤: 「ドメインを発行しなかった」）。
- 部屋さんが、この認識で合っていることを確認した。

## 理由
- 当初の設計から変更し、ドメインを発行しない形で実装した（変更の理由は会議では詳しく語られていない）。

## 影響・トレードオフ
- インフラ側の構成図は、専用ドメインなしの前提に合わせて見直す必要がある。

## 未解決事項・次のアクション
- [ ] （要確認）本番環境も同じパス形式にするか。会議ではステージング環境の話のみ。
- [ ] （要確認）パスの正確な形式。文字起こしが聞き取りにくい。
