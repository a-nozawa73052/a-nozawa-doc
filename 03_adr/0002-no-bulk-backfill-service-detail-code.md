# ADR-0002: 既存契約への提供サービス明細コードの一括洗い替えを見送り、都度対応とする

- 決定者・関係者: 井上充、野澤有沙（UDS）、坪田亜実
- 出典: 文字起こし 00:40:26〜00:44:38

## コンテキスト
- ACEへの本番移行では、現行の契約明細を移行するときに、既存の契約にも「提供サービス明細コード」（ACEで明細を一意に識別するキー）が発番される。システム連携コード（NeOS契約CD）は現行のまま引き継がれる。
- UDSは現在、契約CD（contract_cd）をキーに管理しており、既存の契約には提供サービス明細コードを持っていない。
- 問い合わせ対応などで、提供サービス明細コードが必要になる場面があるかもしれない（野澤）。

## 決定
- 既存契約に提供サービス明細コードを付けるための一括洗い替え（データ移行）は行わない。
- 必要になったときは、問い合わせなどを受けて都度対応する。NeOS契約CDから、ACE側の提供サービス明細を特定する。
- 都度対応で回らなくなった時点で、過去分（3ヶ月〜半年分など）を遡って付けることを検討する。

## 理由
- 対象が数万件にのぼり、一括更新はリスクが高い（井上）。
- 一括で付けなくても、NeOS契約CDがあればACE側の明細を特定できる。プラン変更（バンド変更）があった契約では複数件ヒットするが、件数は限られ、最新のものを採用すればよい（坪田）。

## 影響・トレードオフ
- 移行後しばらくは、UDS内の既存契約の提供サービス明細コードが空欄のままになる。
- 問い合わせ対応では、コードを変換する手間が発生する。

## 未解決事項・次のアクション
- [ ] 「回らなくなった」と判断する基準と、遡及する範囲を決める。
- [ ] ステージング環境でも、既存契約に提供サービス明細コードが発番されるかを確認する（会議では本番環境についてのみ回答があった）。
