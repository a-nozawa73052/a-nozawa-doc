# ADR-0008: UDSのWeb側はテストコードを作成せず、画面での手動確認とする

- 決定者・関係者: 野澤有沙、森晨滉、佐々木航太（UDS）
- 出典: 文字起こし 00:33:45〜00:38:30（Geminiメモ: https://docs.google.com/document/d/1eszIMbszV7HGQ8vf6uHg3BmmEAUMtDb47MF18_1JAkQ）

## コンテキスト
- UDSのWeb側は単体テストがしづらい構成である。
- 今回の修正も、DBに関わるものが多く、単体テストにできるものがほとんどない（佐々木）。
- もともと野澤さんは、Webもテストコード化する想定で依頼していた。

## 決定
- Web側はテストコードを作成しない。従来どおり、画面を手動で操作して確認する。
- ローカル環境での画面確認を行う。開発環境ではWebを触らない前提とする（野澤さん確認済）。
- 森さんが「テストコードにできる」と判断したものがあれば、野澤さんに上げてもらう。

## 理由
- 単体テストにできる修正がなく、画面を操作して確認するしかない（佐々木）。
- 野澤さんは把握不足で依頼していたと述べ、「Webはなしでオッケー」と了承した。

## 影響・トレードオフ
- Webの確認は、ローカルでの画面操作に頼る。量が多い点は懸念として出たが、画面そのものは軽い確認で済む見込み。

## 補足
- Geminiメモは「開発環境での簡易的な確認」とも要約しているが、野澤さんの確認により、開発環境ではWebを触らない前提とした。
- 森さんは以前のUDS開発定例で「Webは自動化が難しい」と聞いていたため、Webのテストコードは考えていなかったと述べた。
